# Site Directory

This directory contains the static brochure website for the grassroots effort to make Narge harder to reach.

## Files

- `index.html` — Main brochure page
- `styles.css` — Stylesheet

## Enabling GitHub Pages

To publish this site:

1. Go to your repository on GitHub
2. Navigate to **Settings** → **Pages**
3. Under **Source**, select **Deploy from a branch**
4. Under **Branch**, select `main` (or your desired branch) and `/site` as the folder
5. Click **Save**

GitHub will build and deploy the site. It will be available at:
```
https://<username>.github.io/<repository-name>/
```

For this repository:
```
https://dov-max.github.io/narge-spec/
```
