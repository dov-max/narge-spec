Get On Cutline

Configure your device or network to use Cutline's DNS resolvers. Use these addresses:

64.176.200.99149.28.79.49
RoutermacOSiPhone/iPadWindowsAndroidApple Profile

Router (Whole Network)

Setting DNS on your router applies the cut path to all devices on your network.Note: Some ISPs lock router DNS settings. If you cannot change DNS, configure individual devices instead.

  1. Open your router's admin panel (usually http://192.168.1.1 or http://192.168.0.1)
  2. Log in with your router credentials
  3. Find the DNS settings (often under "Internet", "WAN", or "DHCP")
  4. Set Primary DNS to 64.176.200.99
  5. Set Secondary DNS to 149.28.79.49
  6. Save and reboot the router
  7. Restart devices or renew DHCP to pick up new DNS

macOS

  1. Open System Settings
  2. Click Network
  3. Select your active connection (Wi-Fi or Ethernet)
  4. Click Details
  5. Go to the DNS tab
  6. Click the + button to add DNS servers
  7. Add 64.176.200.99 and 149.28.79.49
  8. Remove any other DNS servers
  9. Click OK, then Apply

iPhone/iPad (Wi-Fi)

This configures DNS for the specific Wi-Fi network. Repeat for each network you use.

  1. Open Settings
  2. Tap Wi-Fi
  3. Tap the ⓘ next to your connected network
  4. Scroll down and tap Configure DNS
  5. Tap Manual
  6. Remove existing servers (swipe left and delete)
  7. Tap Add Server and enter 64.176.200.99
  8. Tap Add Server and enter 149.28.79.49
  9. Tap Save

For cellular data and easier setup, use the Apple Configuration Profile (see below) when available.

Windows 10/11

  1. Open Settings
  2. Go to Network & Internet
  3. Click your connection type (Wi-Fi or Ethernet)
  4. Click the network name or Properties
  5. Scroll down and click Edit under IP assignment or DNS
  6. Change DNS to Manual
  7. Turn on IPv4
  8. Set Preferred DNS to 64.176.200.99
  9. Set Alternate DNS to 149.28.79.49
  10. Click Save

Android

Instructions vary by Android version and manufacturer. Here's the general process:

Android 9+ (Private DNS)

Note: Private DNS requires DNS-over-TLS (DoT). Cutline does not currently support DoT. Use the Wi-Fi DNS method below instead.

Wi-Fi DNS (All Android versions)

  1. Open Settings
  2. Tap Network & Internet or Connections
  3. Tap Wi-Fi
  4. Long-press or tap the gear icon for your connected network
  5. Tap Modify or Manage network settings
  6. Expand Advanced options
  7. Change IP settings to Static
  8. Scroll to DNS fields
  9. Set DNS 1 to 64.176.200.99
  10. Set DNS 2 to 149.28.79.49
  11. Tap Save
