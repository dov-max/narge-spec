Encrypted DNS (One-Tap Setup)

Cutline now supports DNS-over-HTTPS (DoH) and DNS-over-TLS (DoT). These encrypt your DNS queries end-to-end.

📱 iPhone / Mac

Download and install the configuration profile for one-tap encrypted DNS setup.

  1. Open this page in Safari (profiles only work in Safari)
  2. Tap the button below to download the profile
  3. Go to Settings → Profile Downloaded → Install
  4. Enter your passcode and tap Install (twice)
  5. Install should show Verified, not Not Signed

macOS 26.1+ (Tahoe): If a previous install failed, delete the Downloaded stub in System Settings → General → Device Management first, then install the new file. An admin password prompt is expected (PayloadScope System).

Download Cutline DNS Profile

Note: This profile configures DoH for all networks, including cellular data. You can remove it anytime from Settings → General → VPN & Device Management. This is not MDM and not a content filter.

🤖 Android

Android 9+ has built-in encrypted DNS support.

  1. Open Settings
  2. Go to Network & internet
  3. Tap Private DNS
  4. Select Private DNS provider hostname
  5. Enter: dns.thecutline.org
  6. Tap Save

This configures DNS-over-TLS (DoT) system-wide, including mobile data.

🪟 Windows

Download and run the PowerShell setup script (requires Administrator).

  1. Download the script using the button below
  2. Right-click PowerShell and select Run as Administrator
  3. Navigate to your Downloads folder
  4. Run: .\cutline-dns-windows.ps1
  5. The script registers DoH templates and configures your adapters
Download Windows Setup Script

IPv6 note: The script disables IPv6 DNS bindings by default to prevent leaks. Use -KeepIPv6 flag if needed. Chrome/Edge have separate "Secure DNS" settings that may override system DNS—either point them to the same DoH URL or turn them off.

Router (Whole Network)

Setting DNS on your router applies the cut path to all devices on your network.Note: Some ISPs lock router DNS settings. If you cannot change DNS, configure individual devices instead.

  1. Open your router's admin panel (usually http://192.168.1.1 or http://192.168.0.1)
  2. Log in with your router credentials
  3. Find the DNS settings (often under "Internet", "WAN", or "DHCP")
  4. Set Primary DNS to 64.176.200.99
  5. Set Secondary DNS to 149.28.79.49
  6. Save and reboot the router
  7. Restart devices or renew DHCP to pick up new DNS

macOS

  1. Open System Settings
  2. Click Network
  3. Select your active connection (Wi-Fi or Ethernet)
  4. Click Details
  5. Go to the DNS tab
  6. Click the + button to add DNS servers
  7. Add 64.176.200.99 and 149.28.79.49
  8. Remove any other DNS servers
  9. Click OK, then Apply

iPhone/iPad

Recommended: Use the Apple Configuration Profile above for encrypted DNS on all networks, including cellular.

Alternative (Wi-Fi only, unencrypted): Configure DNS manually for a specific Wi-Fi network.

  1. Open Settings
  2. Tap Wi-Fi
  3. Tap the ⓘ next to your connected network
  4. Scroll down and tap Configure DNS
  5. Tap Manual
  6. Remove existing servers (swipe left and delete)
  7. Tap Add Server and enter 64.176.200.99
  8. Tap Add Server and enter 149.28.79.49
  9. Tap Save

Windows 10/11

Recommended: Use the PowerShell setup script above for encrypted DNS (DoH) with proper configuration.

Alternative (unencrypted): Manually configure DNS servers.

  1. Open Settings
  2. Go to Network & Internet
  3. Click your connection type (Wi-Fi or Ethernet)
  4. Click the network name or Properties
  5. Scroll down and click Edit under IP assignment or DNS
  6. Change DNS to Manual
  7. Turn on IPv4
  8. Set Preferred DNS to 64.176.200.99
  9. Set Alternate DNS to 149.28.79.49
  10. Click Save

IPv6 DNS Leak (Common Issue)

After setting the IPv4 DNS servers above, open PowerShell or Command Prompt and run:

ipconfig /all

Look at the DNS Servers list for your connection. If you see an IPv6 address(especially first in the list), Windows is using that IPv6 resolver and skipping Cutline.

The Settings app "IPv6 DNS Off" toggle does not remove IPv6 resolvers delivered by your router via Router Advertisement or DHCPv6.

Fix: Disable IPv6 on your network adapter.

GUI method:

  1. Press Win+R, type ncpa.cpl, press Enter
  2. Right-click your connection (Wi-Fi or Ethernet), select Properties
  3. Uncheck Internet Protocol Version 6 (TCP/IPv6)
  4. Click OK

PowerShell method (requires Administrator):

Disable-NetAdapterBinding -Name 'Wi-Fi' -ComponentID ms_tcpip6

(Replace 'Wi-Fi' with 'Ethernet' if using a wired connection.)

After disabling IPv6, flush the DNS cache and test:

ipconfig /flushdns

Then visit thecutline.org/verify to confirm you're on the cut path.

Android

Recommended: Use Private DNS (DoT) above for encrypted DNS on all networks, including mobile data.

Alternative (Wi-Fi only, unencrypted): Manually configure DNS for a specific Wi-Fi network.

  1. Open Settings
  2. Tap Network & Internet or Connections
  3. Tap Wi-Fi
  4. Long-press or tap the gear icon for your connected network
  5. Tap Modify or Manage network settings
  6. Expand Advanced options
  7. Change IP settings to Static
  8. Scroll to DNS fields
  9. Set DNS 1 to 64.176.200.99
  10. Set DNS 2 to 149.28.79.49
  11. Tap Save

Note: Steps may vary by Android version and manufacturer.
