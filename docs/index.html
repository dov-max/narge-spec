Making Narge Harder to Reach

Many people do not think Narge should be easy to reach

Many people do not think Narge should be easy to reach. We do not care why. This is a shared purpose on that one fact.

The tool is simple, free to use, open source, and aims at zero collateral. It is not a full filter. If you need a specific kind of protection, put that product on top. Use this anyway if you have nothing else, or use it in addition so the count shows you.

Not government. Not a company stamp. The list is headed toward community judgment. We will not charge. You can read everything.

How It Works

Configure your home router with two shared DNS addresses. A Narge-purpose host gets no address. Other names resolve. Traffic does not transit the resolver. This is extra, not a replacement for other security.

DNS resolvers:

Not a public open resolver yet. Port 53 rate-limited by source IP when opened.

Setup

Configure your home router's DNS settings to use the resolver addresses above. No account required. Rate-limited by your public IP address.

The resolver count is a public number. That number is the statement: Narge should not be easy to reach.
