Cutline

A cut path DNS resolver

Cutline provides a cut path—an internet path that does not resolve the Narge content class. It is a public DNS resolver service you can use right now.

A cut path is not the only path. Anyone may run one. Cutline is one operator. The goal is ordinary internet routing that does not make Narge easy to reach, while keeping everything else reachable.

What is a Cut Path?

A cut path is an internet connection that does not resolve the Narge content class. It is not a full filter, a safety product, or a trust brand. It addresses one narrow technical class.

When you use a cut path DNS resolver like Cutline:

  • Domains identified as Narge-purpose do not resolve (return NXDOMAIN)
  • All other domains resolve normally through upstream DNS
  • Your traffic does not transit the resolver—only DNS queries
  • This is extra protection, not a replacement for other security

What Cutline Is

  • One operator providing a cut path DNS service
  • No signup, no tokens, no accounts
  • Open source configuration and specification
  • No charge to use
  • Run by Dov Allison

What Cutline Is Not

  • Not a house filter, hechsher, government, or kids product
  • Not a "safe/clean/trusted" brand—no shield, guard, or family language
  • Not a movement or coalition—Narge is a content class, not a brand
  • Not the only cut path—anyone can run one
  • Not an addiction treatment or complete filtering solution
