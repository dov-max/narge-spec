Device Setup

iOS / iPadOS / macOSUntested

Download and install the DNS configuration profile for Apple devices.

Download Profile (.mobileconfig)

After download: Open the file and follow the prompts to install. On iOS/iPadOS: Settings → Profile Downloaded → Install. On macOS: System Settings → Privacy & Security → Profiles → Install.

⚠️ This profile points to https://dns.thecutline.org/dns-query which is not responding yet.

AndroidUntested

Configure Private DNS (DNS-over-TLS) in your Android settings.

  1. Open Settings
  2. Go to Network & internet
  3. Tap Private DNS
  4. Select Private DNS provider hostname
  5. Enter: dns.thecutline.org
  6. Tap Save

⚠️ The hostname dns.thecutline.org is not accepting DoT connections yet.

Windows 11Untested

Enable DNS-over-HTTPS in Windows 11 network settings.

  1. Open Settings
  2. Go to Network & Internet
  3. Click on your active network connection (Wi-Fi or Ethernet)
  4. Scroll down and click Edit next to DNS server assignment
  5. Select Manual
  6. Turn on IPv4
  7. In the Preferred DNS field, enter: 64.176.200.99
  8. Set DNS over HTTPS to On (automatic template)
  9. In the Alternate DNS field, enter: 149.28.79.49
  10. Set DNS over HTTPS to On (automatic template)
  11. Click Save

Note: Windows 11 will attempt to discover DoH support automatically. Currently, only plain DNS will work until DoH is live.

⚠️ DoH autodiscovery will not succeed until the service is live.

What is this?

The Cutline provides encrypted DNS resolution that filters Narge content (photorealistic sexual content intended to arouse). Traffic does not transit the resolver - we only handle DNS queries.

This is part of the broader Narge specification effort to make such content harder to reach by default.

Questions or issues? See the narge-spec repository.
