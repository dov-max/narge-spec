Narge Specification

Narge is a class of visual content. It is not a brand, a product, a filter, a religion, or a law.

Version 0.2. 27 August 2026.

The spoken word is NARJ.

Definition

A file, stream, or post is Narge when it is a video or still (including photorealistic AI) of one or more real or photorealistic humans, produced or posted primarily to sexually arouse.

That includes sex acts, masturbation, nudes, and partial nudes when that is the purpose. If the purpose is not arousal, it is not Narge.

If the payload is already a crime under CSAM law, this class does not apply.

Not Narge

Anything that is already a CSAM crime. Written-only text. Non-photoreal illustration. Medical, sex education, news, documentary, breastfeeding, a clothing sale, or a story film, when the purpose is not arousal.

A clip or still cut from a story to arouse is Narge. A link inherits the class of the destination payload.

Rules

  1. Look at the payload, not the domain.
  2. Purpose decides. Two providers may disagree at the margin of a specific picture. That is expected. There are no numbered ratings and no extra classes.
  3. Photoreal counts. Photoreal AI or a deepfake is the same payload if it meets this definition. Consent is a different stack.
  4. The bar is malware, not prohibition. The class can sit off the ordinary trusted path and still be findable if someone tries.

How to Use the Word

That's Narge. A Narge site. This site may contain Narge. This site is promoting Narge. Blocks Narge. A Narge warning.

Do not number it. There is no Narge-1. The bare word means the definition above.

Host List Process

The open process for producing a hostname list based on this definition is documented separately. See the LIST.md file in the repository.

Temporary Feed

Until a public host registry exists, the list pulls from theStevenBlack hosts porn-only list(MIT license, attributed). This is an approximation of Narge, not Narge. It is pulled on a timer.

Overlay Files

Two small public files add corrections:

  • overlay/block.txt — extra hosts to block
  • overlay/allow.txt — StevenBlack entries to unblock

These files exist to refine the temporary feed until a later public host registry exists.
