List Updates

The block list automatically refreshes every 24 hours from upstream sources:

  • StevenBlack porn-only list (MIT license)
  • Overlay corrections from overlay/block.txt and overlay/allow.txt in thenarge-spec repository

No manual VPS access or service restart is needed. Changes to the overlay files are picked up automatically.
